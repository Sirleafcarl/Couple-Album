# Approved modern theme assets

The included backgrounds were generated with the built-in image generator for this project on 2026-09-08. They intentionally contain no UI, captions, example photo cards, or private user photos. Production uses WebP quality 85 plus separate 240×160 thumbnails quality 75. The public edition substitutes a neutral sky placeholder for the original sacred-joy character artwork; that original artwork is not distributed here. Generated provenance is not a blanket warranty of third-party rights or an asset license.

- heart-frequency: ivory with translucent pink/lilac ribbon perimeter.
- sacred-joy: neutral sky placeholder copied from sky-letters; no character artwork included in the public edition.
- love-playground: ivory/blue/yellow/red graphic perimeter with chrome star and red inflated heart.
- blue-holiday: bright coastal architecture and turquoise pool caustics.
- cloud-candy: bright cloud room with small peach glass accents.
- tropical-cutout: bright cut-paper leaves and bird at perimeter.
- clear-specimen: sunlit white studio and small prismatic glass accents.
- heart-track: pale lilac acrylic S-shaped track in a bright studio.
- sky-letters: light blue sky fading to white, cloud wisps only at margins.

daylight and photo-exhibition deliberately have no raster backdrop. Existing classic theme assets are unchanged. Sample photos used by browser tests are served from docs/design-preview fixtures only and are not added to any user's album.
